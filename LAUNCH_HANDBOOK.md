## 3. Deployment Guide (Vercel Ready)
The Hallway is optimized for zero-config deployment on Vercel:

1.  **Environment Sync**: Ensure your Vercel project has the following Environment Variables configured:
    *   `VITE_SUPABASE_URL`: Your Supabase Project API URL.
    *   `VITE_SUPABASE_ANON_KEY`: Your Supabase Anonymous API Key.
2.  **Auth Redirects**: After deployment, add your Vercel URL (e.g., `https://hallway.vercel.app`) to the **Redirect URLs** list in your Supabase Auth settings.
3.  **Database Publication**: Ensure Realtime is enabled for the `notifications` and `messages` tables in your Supabase Dashboard to keep the pulse map alive.
